# WAD Final

## Project Setup

1. Navigate to the Project root and install dependencies using:
```bash
npm install
```

2. Navigate to `src/server` and install dependencies using:
```bash
npm install
```

## Run Development 

There are 3 things necessary to start this project

1. Navigate into `src/` and run command:
```bash
npm run dev
```

2. Navigate into `src/server` and run command:
```bash
npm run dev
```

3. Either **connect to eduroam** (or generally the HTW network) or establish a **VPN connection** to the HTW network.

---

You can then open the project by opening `http://localhost:5173`
